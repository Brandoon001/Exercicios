# Estrutura de Dados com Dicionários em Python

Este repositório contém os exercícios e a implementação prática referente à atividade de **Estruturas de Dados utilizand Dicionários** em Python.

---

## 📌 Sobre o Projeto

O objetivo desta atividade é compreender e praticar a manipulação de dicionários (`dict`) na linguagem Python, explorando conceitos centrais como:

- Criação e inicialização de dicionários (pares chave-valor);
- Acesso, inserção, atualização e remoção de elementos;
- Métodos nativos como `.keys()`, `.values()`, `.items()`, `.get()`, entre outros;
- Iteração e busca eficiente de dados em estruturas do tipo Hash Table.

---
